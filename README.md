## Overview

iZotope Nectar is a comprehensive vocal processing plugin offering pitch correction, harmony generation, breath control, de-essing, EQ, and reverb tailored specifically for vocal production.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **iZotope Nectar** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Vocal Assistant** | AI vocal analysis and automatic processing chain configuration |
| **Pitch Correction** | Real-time pitch correction with natural and robotic modes |
| **Harmony** | Up to 12 harmony voices generated from a single input signal |
| **De-esser** | Multi-band de-essing removes sibilance without affecting other frequencies |
